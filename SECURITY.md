# Security policy

Do not open a public issue for a suspected vulnerability, credential exposure, or customer-data concern.

Report security concerns through the DotMoose support page at https://dotmoose.com/support/ and identify the report as an MCP security issue. Include the affected endpoint, tool name, expected behavior, observed behavior, and safe reproduction steps. Do not include live passwords, access tokens, private keys, payment data, MFA codes, or customer secrets.

DotMoose may ask for additional details through an authenticated support channel.
